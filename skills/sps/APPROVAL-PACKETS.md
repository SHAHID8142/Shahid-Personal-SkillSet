# Approval Packets

Before building each major section or chunk, send a compact approval packet.

## Template

```markdown
## Approval Packet

Section:
Purpose:

Role stack:
- Primary:
- Supporting:

This chunk covers:
- frontend / UI:
- backend / data:
- CMS / content:
- storefront / ERP / admin:
- accessibility:
- performance:
- mobile behavior:
- motion:

Assumptions:
- ...

Trade-offs:
- ...

Next action after approval:
- ...
```

## Rules

- Keep it short.
- State what is intentionally not included in the chunk.
- Mention low-end mobile or performance impact when relevant.
- Do not continue until the user approves.
